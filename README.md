# Future Oracle - сервис прогнозирования погоды

Сервис предсказывает погоду на основе исторических данных и новостей.

Погода - прогнозирование температуры на следующий день для крупных городов России.

# Источники данных

1. OpenWeatherMap API - текущая погода (температура, влажность)
2. Hmn.ru - новости о погоде (анализ тональности)

# База данных

- `weather_data` - исторические данные о погоде
- `weather_news` - новости с тональностью

# Алгоритм прогноза

1. Берутся последние 7 дней из БД
2. Считается средняя температура
3. Вычисляется тренд (повышается/понижается)
4. Прогноз = средняя + (тренд × 0.3)
5. Уверенность зависит от количества данных
6. Новости влияют на уверенность (негативные - снижают)

# API Endpoints

| Метод | URL                   | Описание                |
|-------|-----------------------|-------------------------|
| GET   | `/api/cities`         | Список городов          |
| GET   | `/api/predict/{city}` | Прогноз для города      |
| GET   | `/api/collect-news`   | Сбор новостей (вручную) |
